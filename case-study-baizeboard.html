1 The Brief

Snooker clubs and players had no dedicated digital scoring tool built specifically for the sport. Existing options were either generic, unreliable, or required expensive dedicated hardware.

The client needed a web-based solution — something that could run on any device without installation, handle real match logic, and be robust enough for competitive play where accuracy is non-negotiable.

The key constraints were: it had to work offline, update in real time across multiple screens, and feel purpose-built rather than a generic adaptation.

2 What I Built

  • Full match setup — player names, frame count, and match configuration before play begins
  • Real-time scoring with live sync between the main scoreboard and a companion watch screen
  • Installable as a Progressive Web App (PWA) — works fully offline once installed
  • Connection monitoring with automatic heartbeat so disconnections are caught within 15 seconds
  • Match save and resume — in-progress matches survive app restarts without data loss
  • Fully responsive — designed for tablet use at the table and desktop display on a large screen

The Result

A purpose-built scoring tool that snooker players actually use.

BaizeBoard launched as a fully functional web application — no downloads, no hardware, no subscriptions. It runs on any device with a browser, installs as a PWA, and handles everything from a casual frame between friends to a structured club match. The companion watch screen means a second device can display the score live without any additional setup.
